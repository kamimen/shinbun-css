# 企画

shinbun.css の背景、目的、範囲、設計の原則、計画。出典のリンクは [REFERENCES.md](REFERENCES.md)。

## 背景

- 日経の開発者は、2018 年に、CSS Grid で新聞の紙面を再現する実験を公開した。縦 15 段・横 130 文字幅の Grid、縦組み、2 桁だけの縦中横などを試し、記事の流し込みは JavaScript で行うべきだと結論した（日経 note）。
- Zenn の記事（2022 年）は、`columns` が「段の高さが揃っていなければならない」という制約を持つため、L 字や飛び地は難しいと述べ、JavaScript で計測して流し込む方法を示した。
- GitHub で、日本の新聞スタイル（縦組み・段・段抜き）のための CSS ライブラリを探したが、見つからなかった（2026-10-08、`gh search repos`）。
- 新聞の紙面全体を定める、単一の公開された規格や企画書は、調査した範囲では見つからなかった。日本語組版の規格（JLReq）は、主に書籍を対象としている。

## 目的

日本の新聞紙面の見た目を、依存のない CSS で Web ページに再現できるようにする。そのために、次を満たす。

1. 縦組みと横組みを、同じ書き方で扱える。
2. 記事を「何段 × 何行」の長方形に敷き詰める（ブロック組み）ことができる。
3. 用語と数値に、出典がある。
4. 素の HTML と `data-*` 属性で書ける。公開インターフェースが 1 か所に定義されていて、文書と食い違わない。

## 想定する利用者

- 新聞風のデザインのサイトやブログを作りたい人（Hugo、Astro、素の HTML など）
- 紙面の組版を Web 技術（CSS 組版）で試したい人

## 範囲

- 縦組み・横組みの段グリッド、段抜きの見出し、題字、横見出し、記事、写真、囲み、コラム、表、広告枠
- 規格と出典に基づく用語・設計
- 例と、API リファレンス

## 範囲の外

- 特定の新聞社の紙面デザイン、書体、ロゴの複製
- 日本語組版の完全な実装（ブラウザの責務）
- 記事の自動配置（紙面割付）
- CMS やデータの取り込み

## 設計の原則

1. **規格を優先する。** 規格がある部分（縦組み、段組み、段抜き、縦中横、字下げなど）は、JLReq の用語と記述に従う。
2. **新聞固有の事柄は、出典を付ける。** 出典の本文を読んで確認したことだけを書く。
3. **CSS-first、ビルド不要。** ライブラリを使うのに、Sass も Node もバンドラーも要らない。`src/shinbun.css` をそのまま読み込める。
4. **素の HTML と `data-*` 属性。** クラスを書かなくても、`<article>`、`<h2>` などで組める。配置は `data-sb-*` 属性で書く。
5. **公開インターフェースは 1 か所に定義する。** `src/manifest.json` が唯一の定義で、API リファレンスと CSS の配置属性は、そこから生成する。食い違いは `npm test` が検出する。
6. **実際の紙面づくりの手順に沿う。** あかつき印刷の「紙面レイアウトの基本と応用」が述べる割付の順序（囲み・写真・連載の位置と大きさを先に決め、記事を流し、見出しは最後）は、座標指定の使い方に当たる。

この原則のうち、3〜5 は、Foundation の後継の Yeti（CSS-first、ビルド不要、`data-*` 属性での設定、マニフェストからのドキュメント生成）を参考にした。
